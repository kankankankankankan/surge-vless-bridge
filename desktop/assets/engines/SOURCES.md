# Engine artwork

These assets identify their respective engines. They are bundled locally so the
renderer does not make network requests to display engine choices. Artwork and
trademarks belong to their respective owners; the project MIT license does not
relicense them. No affiliation or endorsement is implied.

Retrieved 2026-11-15:

- `surge.png`: Surge official website, https://nssurge.com/_astro/surge-icon.Deis1Buj.png
- `sing-box.svg`: sing-box official documentation, https://sing-box.sagernet.org/assets/icon.svg
- `mihomo.jpeg`: MetaCubeX official documentation header logo, https://wiki.metacubex.one/assets/images.jpeg

The engine artwork is not a replacement application icon for Surge VLESS Bridge.
